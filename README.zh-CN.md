# 中文界面修改说明

基础版本：上游 v1.5.0.160。中文版发布标记与上游的版本号分开，二进制内部版本仍为 1.5.0.160。

## 修改范围

- `src/platform/uistrings.zh-CN.h`：153 项简体中文显示文字，只在 Windows 上覆盖界面宏。
- `src/platform/uistrings.h`：在 Windows 构建中引入中文头文件。
- `src/platform/win32/`：翻译未使用共用宏的时间、条数、连接状态、窗口错误、最小化按钮和开源致谢。
- `src/ClipboardFlowUi.cpp`：Windows 托盘中的相对时间提示。
- 网络协议、密码派生、加密、剪贴板处理、持久化、隐私和快捷键业务逻辑保持原样。
- `build-zh.ps1`：自动查找 Visual Studio 构建工具，生成普通权限的 Release 构建并运行上游测试。

## 编码与兼容性

中文源码为 UTF-8；沿用上游 MSVC 的 `/utf-8` 编译选项。格式占位符（如诊断复制按钮的 `%d`）保持一致。

中文仅改变显示文字。产品身份、注册表和数据路径、命令行命令、仓库链接和版权信息保持原样。macOS、iOS 和 Linux 的界面或运行行为不在本次中文构建范围内。

## 本地验证

使用 Windows x64、MSVC 14.44.35207、Windows SDK 10.0.26100.0 编译，静态链接运行库及 vcpkg 依赖。

现有 71 个测试、10,041 项断言全部通过；GUI 与 CLI 启动验证通过。检查了主界面、网络、设置上下半页、关于、诊断和历史弹窗。诊断复制按钮的中文数字格式显示正常。

在验证电脑上，系统占用了原版备用快捷键。通过应用设置将其改为 Ctrl+Alt+V 后，快捷键成功注册，历史弹窗打开和关闭正常。此配置不会被打包到发行文件中。

尚未测试真实双设备同步，也未测试全部硬件、系统、缩放、输入法或网络组合。普通权限构建向管理员窗口模拟输入受 Windows 限制。
